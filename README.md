# my-first-repo

Gitの練習用リポジトリです。

## Webページ

https://harukaho-cell.github.io/my-first-repo/

`main` ブランチの直下にあるファイルがそのまま公開されます。
`index.html` を編集して push すれば、1〜2分で公開ページに反映されます。

| ファイル | 内容 |
| --- | --- |
| `index.html` | トップページ（床屋ぐっさん） |
| `sakura-seikotsuin.html` | 以前作った整骨院の練習ページ |
| `.nojekyll` | ファイルをそのまま配信するための設定（中身は空） |
| `hello.py` / `hello.txt` / `*.jpg` | Gitの練習用ファイル |

公開のしくみと、Cloudflare Pagesを使う場合の手順は [DEPLOY.md](DEPLOY.md) にまとめています。
